1. Чем статическая типизация Dart отличается от Python? Какое практическое
преимущество она даёт?
В Dart тип переменной проверяется на этапе компиляции а не во время выполнения. Это позволяет компилятору узнать о ошибке заранее.

2. Что означает String?? Чем отличается от String?
По умолчанию переменная не может содержать null.
String? допускает значение null.

3. Зачем в Dart final, если в Python можно просто договориться не менять
переменную?
Бывают значения, которые должны быть установлены один раз и больше не меняться. Договоренность не спасет от ошибки а компилятор сможет её обнаружить благодаря переменной final.

4. Чем именованный параметр {required String name} отличается от
позиционного? Приведите пример вызова
При позиционном способе значения передаются строго в том же порядке что и объявляются.

void greet(String name, int age) {
  print('Привет, $name! Тебе $age лет.');
}

void main() {
  greet('Иван', 20);
}

Именованный параметр позволяет указывать имя и присваиваемое ему значение при этом порядок передачи не важен. Ключевое слово required означает, что параметр обязательно должен быть передан при вызове.

void greet({required String name, int age = 18}) {
  print('Привет, $name! Тебе $age лет.');
}

greet(name: 'Иван', age: 20); 
или
greet(age: 20, name: 'Иван');
